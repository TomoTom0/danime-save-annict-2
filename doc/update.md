# 更新履歴

## バージョン管理

現在のバージョン: **0.6.5.0**

## バージョン 0.6.5.0 (2025-06-11)

### 主要な変更
- **完全なリライト**: jQuery依存を削除し、モダンなJavaScriptで再実装
- **Manifest V3対応**: Chrome拡張機能の最新仕様に準拠
- **UI/UX改善**: レスポンシブデザインとモダンなインターフェース

### 新機能
- **クラスベース設計**: 保守性とテスタビリティの向上
- **モダン通知システム**: CSS3アニメーションを使用した通知
- **改善されたエラーハンドリング**: より詳細なエラー情報とログ出力
- **複数Webhook対応**: 設定画面からの動的な追加・削除

### 技術的改善
- **jQuery削除**: バンドルサイズの削減とパフォーマンス向上
- **ES6+記法**: async/await、アロー関数、クラス構文の採用
- **セキュリティ強化**: CSP準拠とセキュアな通信
- **ストレージ最適化**: Chrome Storage APIの効率的な使用

### 対応サイト
- dアニメストア (animestore.docomo.ne.jp)
- Amazon Prime Video (amazon.co.jp)
- AbemaTV (abema.tv)

### 開発環境改善
- **テスト構造**: tests/ディレクトリの追加
- **ドキュメント体系**: doc/ディレクトリによる体系的な文書管理
- **プロジェクト管理**: .clinerules、.todo、.doneファイルによる管理

### 削除された機能
- Bootstrap依存（独自CSSに置き換え）
- iziToast依存（独自通知システムに置き換え）
- jQuery依存（ネイティブJavaScriptに置き換え）

## 既知の問題

### 現在の制限事項
- 一部の特殊なエピソード番号表記に対応していない場合がある
- 複数ブラウザ間での同期は未対応
- オフライン時の記録は未対応

### 対応予定
- エピソード番号抽出の改善
- 設定の同期機能
- オフライン対応

## 技術仕様

### 対応ブラウザ
- Chrome 88以降
- Edge 88以降（Chromiumベース）

### 必要な権限
- `storage`: 設定とデータの保存
- `activeTab`: アクティブタブの情報取得
- `https://api.annict.com/*`: Annict APIへのアクセス

### 依存関係
- 外部ライブラリなし（完全ネイティブ実装）
