# danime-save-annict-2 使用方法

## 概要

danime-save-annict-2は、dアニメストア、Amazon Prime Video、AbemaTVの視聴記録を自動でAnnictに送信するChrome拡張機能です。

## インストール方法

### Chrome Web Storeからのインストール（推奨）
1. [Chrome Web Store](https://chrome.google.com/webstore/)にアクセス
2. "danime-save-annict-2"を検索
3. 「Chromeに追加」をクリック

### 開発版のインストール
1. 本リポジトリをクローンまたはダウンロード
2. Chromeで`chrome://extensions/`にアクセス
3. 「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. `src`フォルダを選択

## 初期設定

### 1. Annict APIトークンの取得
1. [Annict](https://annict.com/)にログイン
2. [設定 > アプリ](https://annict.com/settings/apps)にアクセス
3. 「アクセストークンを発行」をクリック
4. 必要な権限を選択（最低限「記録の作成」が必要）
5. トークンをコピー

### 2. 拡張機能の設定
1. 拡張機能のアイコンを右クリック
2. 「オプション」を選択
3. Annict APIトークンを入力
4. 必要に応じてその他の設定を調整
5. 「設定を保存」をクリック

## 基本的な使用方法

### 自動記録
1. 対応サイトでアニメを視聴
2. 拡張機能が自動的にアニメ情報を検出
3. Annictに視聴記録が送信される
4. 右上に通知が表示される

### 対応サイト
- **dアニメストア** (animestore.docomo.ne.jp)
- **Amazon Prime Video** (amazon.co.jp)
- **AbemaTV** (abema.tv)

## 設定項目

### 基本設定
- **Annict APIトークン**: Annictとの連携に必要（必須）
- **自動送信**: 視聴記録の自動送信を有効/無効
- **デバッグモード**: 詳細なログ出力を有効/無効

### Webhook設定
- **Webhookを有効にする**: 外部サービスへの通知を有効/無効
- **Webhook URL**: 通知先のURL（複数設定可能）

## 機能詳細

### 重複防止機能
- 同じエピソードの重複送信を自動防止
- ブラウザのローカルストレージに送信履歴を保存

### 通知システム
- 送信成功時: 緑色の通知
- エラー時: 赤色の通知
- 3秒後に自動で消える

### Webhook通知
送信されるデータ形式：
```json
{
  "text": "アニメタイトル 第X話を視聴しました (サイト名)"
}
```

## トラブルシューティング

### よくある問題

#### 1. 記録が送信されない
- Annict APIトークンが正しく設定されているか確認
- 対応サイトで視聴しているか確認
- デバッグモードを有効にしてコンソールログを確認

#### 2. 接続テストが失敗する
- インターネット接続を確認
- Annict APIトークンの有効性を確認
- Annictのサービス状況を確認

#### 3. 重複して記録される
- 通常は重複防止機能が働きます
- 複数のブラウザや端末で使用している場合は重複する可能性があります

### デバッグ方法
1. 設定画面で「デバッグモード」を有効
2. Chromeの開発者ツールを開く（F12）
3. コンソールタブで`[DanimeAnnict]`のログを確認

### よくある質問
- **Q: 劇場版アニメに対応していますか？**  
  A: はい、対応しています。エピソード番号が正しく抽出されない場合があります。

- **Q: 複数のWebhookを設定できますか？**  
  A: はい、設定画面で複数のWebhook URLを追加できます。

- **Q: 視聴履歴はどこに保存されますか？**  
  A: Chromeのローカルストレージに保存され、拡張機能をアンインストールすると削除されます。
